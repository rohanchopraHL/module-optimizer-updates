# Module Optimizer 2.0 - what's new
#
# Shown to the team in Blender's What's new popup (opens by itself
# when a new version is ready). Write the notes for the next
# publish under "next" - build_zip.py replaces it with the version
# number. Keep each line short; lines starting with # are ignored.

2.0.40
- New Category "Wardrobe Internals": all the Wardrobe Internals add-on tools are now inside Module Optimizer 2.0 - you can remove the separate Wardrobe Internals add-on
- Wardrobe Internals > Auto Optimize: the Internal Optimizer in one click - Optimize names every part (using STEP 1's Name), adds drawer handles and the hanger rod (name with HR), centred like Set Pivot Point
- Wardrobe Internals > Set Pivot Point: centres on the panels only (handles / hanger rod no longer pull the centre forward)
- Wardrobe Internals: new layout - cleanup buttons, then module name with Optimize Internal right under Apply Module Name, then Convention (Panel Conventions only), Flip, UV Checker, Resizer (choose Depth or Width) and Export; Nudge and Hardware Library removed from the panel
- Auto Optimize hanger rods match the team's files: full width without a vertical panel (half right beside one), 85 mm under the panel above, as many as the name's HR count; WTR racks go into their drawer box
- Wardrobe Internals: CleanUp Module now sets the scene units to Millimeters, scales (measures the module, any import scale) and deletes the materials - it no longer deletes or joins any mesh; Delete Empty Groups is now Delete Empty Groups/Remove Shell
- Auto Optimize follows the team's naming: name kept as typed, parts in metres, glass panels int-dwr-gl, FS / RS counts from the name, handles only on ID drawers (never OD / ODB or the trouser rack), LK box panels on their own
- Auto Optimize: GLU modules get the 4 metal parts (mtl-blk / mtl-chrm) sized to the internal; trouser racks (WTR) become one int-dwr of their own
- Cabinets > Carcass > Without OSL/BSL: the bed storage parts (Bottom Storage Panels, Center Vertical, Horizontal Rippers Left / Right, Side Supports, Top Matress Panels) now each become their own car-in, instead of one joined car-in
- Cabinets > Shutter: the bed parts moved from All Combine to Combine Front and Back - Bed Side Panel Left / Right and Bed Footboard each their own sh_NN (sh-ft Front + Back, sh-eb); all Headboard parts in one sh_NN. All Combine is back to Curved End Panels only

2.0.39
- Category dropdown now has only Cabinets and Wardrobes (Beds, Storages and Tables removed)
- Cabinets > Shutter > All Combine also finds Bed Side Panel Left / Right and Bed Footboard (each whole), and the Headboard (Head board, back rippers, side and top frames joined into one)
- Cabinets > Carcass > Without OSL/BSL also finds the bed storage parts (Bottom Storage Panel 1, 2 ..., Center Vertical, Horizontal Rippers Left / Right, Side Support Left / Right, Top Matress Panel 1, 2 ...) and joins them all into one car-in

2.0.38
- New Category dropdown at the top (starts on "Select"): Cabinets, Wardrobes, Beds, Storages, Tables. Pick Cabinets for all the tools you know; the others share the general tools, with their own conventions coming soon
- Skirting: type any Height and Depth in mm (starts at 100 x 18mm)
- Wardrobes: Top / Back / Side / Bottom Panel find "Top Panel 1, 2 ...", "Side Panel Left / Right" etc. and ask With OSL/BSL or Without; click again to switch
- Wardrobes: Shutter (no popup) finds "Hinged Wardrobe Plain Left / Right 1, 2 ..." - each sh_NN with sh-ft, sh-bk, sh-eb
- Wardrobes: Vertical Panel finds "Centre Vertical Panel 1, 2 ..." - vt-pnl_01, _02 ...
- Wardrobes: Carcass, Removable Shelf and Fixed Shelf are coming soon
- Wardrobes > Handle Library: With Lock / Without Lock for one shutter - a lock 35mm under the handle, named lck_01, _02 ... (not shown with Add Handle to Selected)
- Handle Library: selected shutter groups (sh_01, sh_02 ...) now count as their front face
- Cabinets: panel buttons now in the order Top, Back, Side, Bottom
- Beds: no Handle Library or Skirting

2.0.37
- Handle Library: select two or more meshes and click "Add Handle to Selected" - each gets a handle with the same settings

2.0.36
- Handle Library: Horizontal handles now use Height Position too (% from the bottom, 50% = centre) instead of Top / Center / Bottom

2.0.35
- Handle Library: Vertical handles now have Side (Left / Right) and Height Position - % from the bottom of the shutter to the handle's centre (50% = middle)
- Handle Library: Object / Pick moved above Horizontal / Vertical

2.0.34
- Skirting: choose Depth (18mm / 20mm) and Position - Inline (in front, as before) or Inset (inside, between the side panels, flush with the front)

2.0.33

2.0.32
